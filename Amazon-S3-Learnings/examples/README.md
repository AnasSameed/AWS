# Examples

- `cors-configuration.json`: example CORS rules for one frontend origin.
- `deny-insecure-transport-bucket-policy.json`: denies HTTP / non-TLS requests.
- `iam-read-only-prefix-policy.json`: grants read access to objects under a sample `reports/` prefix.
- `lifecycle-rule-example.json`: illustrative lifecycle rule; review retention and cost before use.

Replace placeholders and validate each example against your actual use case. CORS is not a substitute for S3 authorization.
